# Launch Plan

Agent Memory Site turns Markdown/Obsidian AI-agent memory vaults into semantic HTML dashboards, search indexes, and retrieval-ready JSONL chunks.

Core phrase:

> Markdown is the database. Semantic HTML is the interface. JSONL is the retrieval layer.

## Launch copy

### Hacker News

```text
Show HN: Agent Memory Site – Markdown memory vaults to semantic HTML + JSONL

I built Agent Memory Site, an open-source CLI that turns Markdown/Obsidian-style AI-agent memory vaults into a static semantic HTML dashboard plus retrieval-ready artifacts: search-index.json, manifest.json, and chunks.jsonl.

The idea is: Markdown is the database, semantic HTML is the interface, JSONL is the retrieval layer.

It is local-first and privacy-aware: notes can be marked public/private/team and sensitive notes are excluded from public exports by default.

GitHub: https://github.com/nikopastore/agent-memory-site
Demo: https://nikopastore.github.io/agent-memory-site/
```
